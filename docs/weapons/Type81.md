# Referenční karta – Type 81 (PLA Medic)

Pevná sestava: Type 81 s pevnou dřevěnou pažbou (výtvarně předepsaná varianta), mechanická mířidla.
Vlastní proporce oproti AKM: delší štíhlé dolní předpažbí s průduchy, krátké horní předpažbí
a kovový tepelný kryt plynové trubice, regulátor plynu vpředu na plynovém bloku, vysoký sloupek
mušky s otevřenými křidélky blíž k bloku, dlouhé ústí s kroužky pro nástřelné granáty, přímější
pažba s kovovou botkou, zaoblený zadek pouzdra, malý selektor vlevo, světlejší hnědooranžové dřevo.

| Položka | Stav | Hodnota v modelu |
|---|---|---|
| Celková délka | umělecký odhad | 0,99 m (jmenovitě ~0,95 m) |
| Záměrná přímka | umělecký odhad | 0,27 m |
| Oko za hledím | herní úprava | 0,33 m |

Reference pro Type 81 v tomto prostředí **nebyla k dispozici**; konstrukční znaky jsou z obecné
znalosti a musí projít ověřením (zadání: vlastní referenční karta před finální geometrií). Model proto
považujte za funkční výtvarný návrh, ne za ověřenou předlohu.
